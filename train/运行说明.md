# 实验一：目标检测与识别 —— 运行说明

## 一、项目简介

本项目实现桌面物体的目标检测与识别。使用 **YOLOv8** 模型，对自采数据集中
**键盘（keyboard）、农夫山泉瓶（nongfu_spring）、手机（phone）** 三类桌面物体进行检测，
最终部署到 Jetson 平台实时运行，并通过 ROS2 发布识别结果。

最终模型在验证集上 **mAP50 = 0.944**，测试集正确识别率 **92.5%**（conf=0.5），
满足实验验收标准（正确识别率 ≥ 80%）。

## 四、数据集准备

数据集为自拍自标数据，共 **682 张** 桌面场景图片（train 488 / valid 90 / test 104），
已按 YOLO 格式整理在 `dataset_self/` 目录下：

```
dataset_self/
├── data.yaml          # train/val/test 路径与类别定义
├── train/images/      # 训练图片（jpg）
├── train/labels/      # 训练标注（txt，格式：class cx cy w h）
├── valid/images/      # 验证图片
├── valid/labels/      # 验证标注
├── test/images/       # 测试图片
└── test/labels/       # 测试标注
```

标注格式说明（每行一个目标）：

```
类别id  中心点x(归一化)  中心点y(归一化)  宽度w(归一化)  高度h(归一化)
```

类别 id 对应关系：`0 = keyboard`，`1 = nongfu_spring`，`2 = phone`。

> 提示：若使用自己的数据集，请保证目录结构一致，并修改 `data.yaml` 中的路径与类别名。

## 五、模型训练

### 1. 直接运行训练脚本

```bash
cd train
python3 train.py
```

脚本会自动完成以下工作：

1. **自动检测设备**：优先 CUDA（NVIDIA GPU），其次 MPS（Apple Silicon），最后 CPU；
2. **按设备调整默认参数**：GPU 下 epochs=600、imgsz=640、batch=2；
3. **加载 COCO 预训练权重** `yolov8m.pt`（首次运行自动下载）；
4. **训练**：强数据增强（Mosaic、MixUp、随机擦除、几何/颜色增强）+ 余弦退火学习率
   + 早停（验证集连续 100 轮无提升自动停止）；
5. **测试集评估**：训练完成后自动用 `best.pt` 在测试集上计算 mAP50 / mAP50-95。

### 2. 自定义参数

```bash
# 指定数据集路径
python3 train.py --data /path/to/data.yaml

# 自定义训练轮数 / 图片尺寸 / batch
python3 train.py --epochs 300 --imgsz 640 --batch 4

# 指定模型大小（n/s/m/l/x）
python3 train.py --model yolov8s.pt
```

### 3. 常用参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--data` | 自动找 `../dataset_self/data.yaml` | 数据集配置文件 |
| `--model` | `yolov8m.pt` | 预训练模型，n 最小最快，x 最大最准 |
| `--epochs` | 600（GPU） | 训练轮数，配合早停一般 200 轮内收敛 |
| `--imgsz` | 640 | 输入图片尺寸 |
| `--batch` | 2（GPU） | 批大小，8GB 显存跑 yolov8m 建议 ≤ 2 |
| `--device` | 自动 | 手动指定 `cuda` / `cpu` / `mps` |
| `--patience` | 100 | 早停轮数 |

### 4. 训练结果

训练结束后生成在 `train/runs/desktop_train/` 目录：

```
runs/desktop_train/
├── weights/
│   ├── best.pt        # 验证集指标最优的权重（用于部署）
│   └── last.pt        # 最后一轮权重（可用于断点续训）
├── results.png        # 训练曲线（loss / mAP）
├── confusion_matrix.png
└── ...
```

### 5. 注意事项

- **显存不足（OOM）**：报 `CUDA out of memory` 时减小 `--batch`（4→2→1），或换小模型 `--model yolov8s.pt`；
- **Docker 共享内存不足**：报 `Bus error` 时降低 DataLoader 进程数（脚本会自动检测 /dev/shm，必要时手动加 `--workers 2`）；
- **MPS 报错**：Apple Silicon 上若遇到 NMS 相关报错，脚本已自动设置 `PYTORCH_ENABLE_MPS_FALLBACK=1`；
- **早停提前结束**：属正常现象，`best.pt` 已保存训练过程中最优权重。

## 六、模型测试与评估

### 1. 测试集推理（保存检测结果）

```bash
cd train
yolo detect predict model=runs/desktop_train/weights/best.pt \
    source=../dataset_self/test/images conf=0.5 save_txt=True save_conf=True
```

结果保存在 `runs/detect/predict/`：图片带检测框，`labels/` 下为文本结果
（格式：`类别id cx cy w h 置信度`）。

### 2. 量化评估（正确识别率 / 误检 / 漏检）

```bash
python3 eval_predict.py runs/detect/predict/labels ../dataset_self/test/labels 0.5
```

输出各类别的 TP / FP / FN / Precision / Recall / 正确识别率，
以及误检、漏检的具体图片清单（可作为实验报告的错误案例）。

### 3. 阈值选择

测试时可用不同置信度阈值对比（0.4 / 0.5 / 0.6），在误检与漏检之间取平衡。
本项目最终选择 **conf=0.5**：正确识别率 92.5%，平均每张图误检不到 1 个框。

## 七、Jetson 部署（可选）

1. **导出模型**（在训练机上）：

   ```bash
   yolo export model=runs/desktop_train/weights/best.pt format=engine device=0 imgsz=640
   ```

2. **运行 ROS2 发布节点**（Jetson 上）：

   ```bash
   pip install ultralytics opencv-python
   python3 ros2/yolo_detector_node.py --ros-args \
       -p model_path:=/home/nvidia/best.pt -p camera_id:=2 -p conf:=0.5
   ```

3. **查看识别结果**：

   ```bash
   ros2 topic echo /detections/json
   ```

## 八、常见问题

**Q1：找不到 data.yaml**
使用 `--data` 指定数据集配置文件的绝对路径。

**Q2：训练速度太慢 / 显存不足**
减小 `--batch` 和 `--imgsz`，或换用 `--model yolov8s.pt`（更小更快）。

**Q3：测试集准确率高但摄像头实测一般**
训练数据与 Jetson 摄像头画面存在领域差异。建议用 Jetson 摄像头补拍 50~100 张
真实画面，自动标注后人工修正，再在原模型基础上微调一轮。
